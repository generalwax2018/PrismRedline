# Security Policy

## Authorized use only

PrismRedline is an **offensive security tool** intended for authorized
penetration testing and security research. By using it you agree to:

- Operate **only** against systems you own or have **explicit written
  permission** to test.
- Comply with all applicable laws and the rules of engagement for your
  assessment.

The authors accept **no liability** for misuse or for any damage caused by
this software. Unauthorized access to computer systems is illegal in most
jurisdictions.

## Reporting a vulnerability in PrismRedline

If you find a security issue in PrismRedline itself (not in a target system),
please report it responsibly:

- **Do not** open a public issue for a sensitive vulnerability.
- Email the maintainer or open a GitHub [private security advisory]
  (https://docs.github.com/en/code-security/security-advisories).
- Include a description, reproduction steps, and the affected version/commit.

We aim to acknowledge reports within a few days and will credit reporters who
wish to be named.

## Supported versions

This is early-stage software. Only the latest `main` is supported until a
tagged release line is established.
